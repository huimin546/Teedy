## Tutorial9 Jenkins CI/CD Pipeline 修复

- 问题：Jenkins build 持续失败，用户已改为 Windows bat 语法和绝对路径但仍报错
- 根因分析：
  1. JaCoCo stage 单独运行 `jacoco:report` 在 `clean` 之后找不到 `.exec` 文件（需先跑 test）
  2. Site stage 没有 `-DskipTests`，导致重跑测试耗时还可能失败
  3. pom.xml 的 `<reporting>` 缺少 `maven-javadoc-plugin` 声明（PDF 要求的）
  4. `junit` 步骤没有 `allowEmptyResults: true`，若某模块无测试报告会报错
- 修复内容：
  - `Jenkinsfile`：Site 加 `-DskipTests -Ddoclint=none`，junit 加 `allowEmptyResults: true`
  - `pom.xml` `<reporting>` 部分：增加 `maven-javadoc-plugin 3.5.0`（doclint=none）和 `jacoco-maven-plugin` 的 report reportSet
- 已 commit & push：`18a8bf4` → `master`
